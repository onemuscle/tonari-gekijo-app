プライバシーポリシー

対象：「となりの暮らし劇場 分析」（以下「本ツール」）／制定日：2026年11月18日

1. 本ツールについて

本ツールは、YouTube チャンネル「となりの暮らし劇場」の運営者が、自分のチャンネルを管理するためだけに使う内部ツールです。運営者以外の方の Google アカウントやデータには、アクセスしません。

2. 取得するデータ

運営者が Google の画面で許可した範囲で、次のデータを取得します。

  • 自分のチャンネルの統計（視聴回数・視聴時間・視聴者維持率・登録者の増減・流入元・インプレッション数とクリック率）：YouTube Analytics API、YouTube Reporting API
  • 自分のチャンネルの動画・再生リストの情報（タイトル・説明・公開設定）：YouTube Data API

視聴者個人を特定できる情報（氏名・メールアドレスなど）は取得しません。統計は YouTube が集計した数値のみです。

3. 使い方

  • チャンネルの分析（どの動画がどれだけ見られているか）と、動画のタイトル・説明・再生リスト・字幕・公開予約の更新にのみ使います
  • 更新は、運営者が内容を確認したあとにだけ行います
  • 広告、販売、第三者への提供には使いません

4. 保存と管理

  • Google の認証情報（アクセストークン）は、運営者のパソコンの中にだけ保存し、外部に送りません
  • 集計した統計は、運営者のパソコンと、運営者だけが見られる非公開のリポジトリに保存します
  • データは分析に必要な期間だけ保持し、不要になれば削除します

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

YouTube のデータの扱いには、YouTube 利用規約と Google プライバシー ポリシーが適用されます。

6. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
