となりの暮らし劇場 分析

YouTube チャンネル「となりの暮らし劇場」の運営者が、自分のチャンネルを管理するために使う内部ツールです。一般の方に提供するサービスではありません。

このツールがすること

  • チャンネルの運営者本人の許可のもとで、YouTube Analytics API と YouTube Reporting API から、自分のチャンネルの視聴回数・視聴時間・登録者数・流入元・インプレッションのクリック率を読み取ります
  • YouTube Data API で、自分のチャンネルの動画のタイトル・説明・再生リスト・字幕・公開予約を更新します（運営者が内容を確認したあとに限ります）
